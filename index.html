  • RAG-QA Chatbot

    For this project, I focused on building a context-aware Retrieval-Augmented Generation (RAG) chatbot using modern AI frameworks and tools. Leveraging Large Language Models (LLMs), vector databases, and retrieval pipelines, the chatbot delivers accurate and contextually relevant answers from unstructured data sources. The system is architected using Python, LangChain, FastAPI, and Streamlit, combining LLM-driven natural language processing with real-time user interaction.

    I used LangChain to orchestrate the flow between document retrieval and LLM prompting. FastAPI serves as the backend API layer, managing interactions between the user interface, the vector database (ChromaDB), and the LLMs. By embedding documents into vector space using LangChain’s retrieval pipeline and storing them in ChromaDB, the system performs fast and efficient similarity searches based on user queries. This architecture ensures responses are grounded in retrieved content, increasing both accuracy and reliability.

    On the frontend, Streamlit was used to develop a clean, user-friendly interface for real-time question answering. Users can input natural language queries, which are then processed through the backend pipeline. Retrieved documents are passed to the LLM, which synthesizes a response based on the content. The system is compatible with both OpenAI models and local LLMs via Ollama, supporting models like Mistral and LLaMA for flexible deployment.

    This project demonstrates my ability to integrate retrieval mechanisms with generative models, handle vector database operations, and build end-to-end applications that combine multiple AI components. It highlights my skills in prompt engineering, API development, and full-stack LLM applications. The modular and scalable design allows easy adaptation for enterprise-level knowledge assistants or internal document Q&A tools.


    Technologies: Python, FastAPI, Streamlit, LangChain, ChromaDB, Ollama, OpenAI, Large Language Models (LLMs).

    GitHub: https://github.com/NourEldin-Ali/RAG-QA-Chatbot

  • Natural Language to BPMN/UML/Business Data using LLM

    For this project, I focused on leveraging cutting-edge technologies like Large Language Models (LLMs) and implementing prompt engineering techniques to automate business process modeling. Using Python, Flask, and Langchain, I built a hybrid system that integrates LLM-based text analysis with a structured algorithmic approach. This approach decomposes the complex task of generating business process models from textual descriptions into manageable sub-tasks. The LLM analyzes, clarifies, and extracts process entities such as activities and dependencies, while the modular pipeline provides users with an interactive platform for validating or updating extracted information, resulting in highly accurate BPMN models.

    Additionally, I utilized the power of Python and Langchain to integrate the LLM's natural language understanding capabilities within a scalable web framework developed using Flask. This hybrid system not only improves efficiency by reducing token usage but also enhances the accuracy and relevance of generated models. By breaking down the process modeling into distinct steps, this project showcases my skills in prompt engineering, Python development, and the use of AI technologies to solve real-world problems, offering an innovative approach to handling incomplete or non-expert descriptions in process automation.

    Furthermore, the project extends its capabilities to support the transformation of textual descriptions into Unified Modeling Language (UML) diagrams. The system extracts structural and behavioral elements from the text, such as classes, attributes, methods, and their relationships, to automatically generate accurate UML diagrams, including class diagrams and sequence diagrams. This functionality aids in visualizing complex software architectures and enhances the clarity of system designs derived from natural language inputs.

    In addition to BPMN and UML generation, the system is designed to transform textual data into business data models that can be directly used to execute BPMN workflows. By mapping the extracted entities and process details into executable business data formats, the project facilitates seamless integration with BPMN engines, thereby enabling automated process execution. This capability ensures that the generated models are not only descriptive but also operational, bridging the gap between process design and execution.


    Technologies: Python, Flask, Langchain, Large Language Models (LLMs), BPMN, nodejs (Vite Framework), AWS, plantUML.

  • Generate Cartoon Faces using StyleGan

    I fine-tuned StyleGAN to generate high-quality cartoon faces. Using a custom dataset, I adapted the model to produce diverse cartoon images with distinct features. Moreover, I modified the original StyleGAN architecture to incorporate conditional inputs, allowing precise control over the generated faces. This enhancement enables the generation of cartoon faces with specific attributes, such as gender (male or female), age (young or old), and skin tone. These customizations were achieved by manipulating the latent space and refining the model to respond to these conditions, ensuring the output meets the desired criteria.

    Indeed, I modified facial emotions in generated images by manipulating the latent space directions of StyleGAN. I explored specific vectors in the latent space that correspond to various emotions like happiness, sadness, anger, and surprise. By adjusting the direction of these vectors, I was able to seamlessly change the emotional expression of generated faces while maintaining their core identity and other attributes, such as gender and age. This approach allows for precise and dynamic control over facial emotions in generated images, demonstrating the power of StyleGAN's latent space manipulation.


    Technologies: Python, Pytorch, StyleGAN2, Google Colab, Google Cloud Platform.
